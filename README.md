### 🔬 Research Project

#### 🧠 Aurevia — Multimodal AI-Based Burnout Detection

A research project exploring burnout detection through text and voice analysis using Artificial Intelligence and Machine Learning.

**Key Components:**

- 📝 BERT-based text analysis for burnout-related language patterns.
- 🎙️ CNN-based voice emotion recognition.
- 🔗 Multimodal fusion combining text and voice predictions.
- 🌐 React.js frontend for user interaction.
- ⚡ FastAPI backend for model integration.
- 🗄️ Supabase and PostgreSQL for data storage.

**Technologies:** `Python` `BERT` `CNN` `React.js` `FastAPI` `Supabase` `PostgreSQL`
